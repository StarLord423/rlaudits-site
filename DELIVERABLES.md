# RL Audits Site Deliverables

## Produced artifacts

- Public static website files.
- SEO/static routing files such as `robots.txt`, `sitemap.xml`, and `404.html`.
- Shared assets under `assets/`.

## Delivery destinations

- Public domain: `https://rlaudits.com/`.
- WWW domain: `https://www.rlaudits.com/`.
- GitHub remote: `https://github.com/StarLord423/rlaudits-site.git`.

## Review process

1. Verify changed files locally.
2. Check for accidental internal/private paths.
3. Get Squatch approval before push/deploy.
4. Verify public URLs after deploy.

## Do not deliver without approval

- Public deploys.
- GitHub pushes.
- Offer/pricing changes.
- Client-facing claims that Squatch has not approved.
